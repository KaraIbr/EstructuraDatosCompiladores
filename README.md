El siguiente repositorio tiene fines educativos para la materia de estructura de datos y compiladores 

La estructura es: 

Ordenamientos: codigos con pseudocogido que sirvan de referencia asi como las notaciones de su rendimiento 

Visualizaciones: uso de la biblioteca thinker para tener un algoritmo grafico inspirado en sitios web como https://www.alg0.dev/

Prueba comparativa con el mismo arreglo para ver la eficacia de cada uno. 

Para su elaboracion se referencia el material de clase compartido por la maestra
